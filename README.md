## 🚀 Overview

CineMatch AI is a content-based movie recommendation system that suggests similar movies using genre analysis and cosine similarity.

The project transforms movie genres into numerical representations and identifies relationships between movies based on their content characteristics.

---

## 🧠 Technologies Used

- Python
- Pandas
- Scikit-learn
- CountVectorizer
- Cosine Similarity

---

## 📊 Features

- Movie recommendation engine
- Content-based filtering
- Genre similarity analysis
- Cosine similarity matching
- Fast recommendation generation
- Simple and interpretable model
